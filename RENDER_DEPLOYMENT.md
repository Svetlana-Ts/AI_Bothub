# 🚀 Инструкция по деплою на Render.com

## Подготовка

### 1. Убедитесь, что у вас есть:
- ✅ Аккаунт на [Render.com](https://render.com)
- ✅ Репозиторий на GitHub/GitLab/Bitbucket
- ✅ OpenAI API ключ

### 2. Проверьте файлы проекта:
- ✅ `render.yaml` - конфигурация для Render
- ✅ `Dockerfile` - комбинированный Dockerfile для сборки
- ✅ Код закоммичен и запушен в репозиторий

## Шаги деплоя

### Шаг 1: Подключение репозитория

1. Войдите в [Render Dashboard](https://dashboard.render.com)
2. Нажмите **"New +"** → **"Blueprint"** (или **"New Static Site"** если Blueprint недоступен)
3. Подключите ваш Git репозиторий:
   - Выберите провайдера (GitHub/GitLab/Bitbucket)
   - Авторизуйтесь и выберите репозиторий
   - Выберите ветку (обычно `main` или `master`)

### Шаг 2: Настройка через Blueprint (render.yaml)

Если вы используете Blueprint:

1. Render автоматически обнаружит файл `render.yaml`
2. Нажмите **"Apply"** для создания сервисов
3. Перейдите к шагу 3

### Шаг 3: Ручная настройка (если Blueprint не используется)

Если Blueprint недоступен, создайте Web Service вручную:

1. Нажмите **"New +"** → **"Web Service"**
2. Подключите репозиторий (если еще не подключен)
3. Настройте сервис:
   - **Name**: `bothubchat`
   - **Environment**: `Docker`
   - **Region**: Выберите ближайший (например, `Frankfurt` или `Oregon`)
   - **Branch**: `main`
   - **Root Directory**: оставьте пустым (корень проекта)
   - **Dockerfile Path**: `./Dockerfile`
   - **Docker Build Context**: `.` (точка)
   - **Docker Command**: оставьте пустым (используется CMD из Dockerfile)

### Шаг 4: Настройка переменных окружения

В настройках сервиса перейдите в раздел **"Environment"** и добавьте:

- **OPENAI_API_KEY**: ваш OpenAI API ключ (нажмите "Sync" = false, чтобы скрыть значение)
- **NODE_ENV**: `production` (уже настроено в render.yaml)
- **PORT**: `3000` (уже настроено в render.yaml)

**Важно**: Не коммитьте API ключи в репозиторий! Используйте переменные окружения Render.

### Шаг 5: Выбор плана

1. Выберите план:
   - **Free**: подходит для тестирования (может "засыпать" после неактивности)
   - **Starter** ($7/мес): рекомендуется для production (всегда активен)

2. Нажмите **"Create Web Service"**

### Шаг 6: Ожидание деплоя

1. Render начнет сборку Docker образа
2. Процесс может занять 5-10 минут при первом деплое
3. Следите за логами в разделе **"Logs"**
4. После успешного деплоя вы увидите URL вида: `https://bothubchat.onrender.com`

### Шаг 7: Проверка работы

1. Откройте URL вашего приложения
2. Проверьте работу чата:
   - Отправьте тестовое сообщение
   - Убедитесь, что получаете ответ от AI
3. Проверьте API напрямую:
   ```bash
   curl -X POST https://your-app.onrender.com/api/chat \
     -H "Content-Type: application/json" \
     -d '{
       "message": "Привет!",
       "systemPrompt": "Ты помощник"
     }'
   ```

## Автоматический деплой

После настройки, каждый push в ветку `main` автоматически запустит новый деплой (если `autoDeploy: true` в render.yaml).

## Мониторинг и логи

- **Logs**: Просмотр логов в реальном времени в разделе "Logs"
- **Metrics**: Мониторинг использования ресурсов
- **Events**: История деплоев и событий

## Обновление приложения

### Автоматическое обновление:
```bash
git add .
git commit -m "Update application"
git push origin main
```
Render автоматически обнаружит изменения и запустит новый деплой.

### Ручной деплой:
1. В Render Dashboard выберите ваш сервис
2. Нажмите **"Manual Deploy"** → **"Deploy latest commit"**

## Решение проблем

### Приложение не запускается

1. **Проверьте логи** в разделе "Logs"
2. **Проверьте переменные окружения**:
   - Убедитесь, что `OPENAI_API_KEY` установлен
   - Проверьте, что `PORT=3000`
3. **Проверьте Dockerfile**:
   - Убедитесь, что Dockerfile находится в корне проекта
   - Проверьте, что все пути правильные

### Ошибка "Build failed"

1. Проверьте логи сборки
2. Убедитесь, что все зависимости указаны в `package.json`
3. Проверьте, что Node.js версия совместима (используется Node 20)

### Приложение "засыпает" (Free план)

На Free плане приложение может "засыпать" после 15 минут неактивности. Первый запрос после пробуждения может занять 30-60 секунд.

**Решение**: Перейдите на Starter план ($7/мес) для постоянной работы.

### CORS ошибки

Если вы видите CORS ошибки, проверьте настройки в `server/index.js`. Код уже настроен для работы с Render.

### API не отвечает

1. Проверьте, что `OPENAI_API_KEY` правильный и активный
2. Проверьте логи сервера на наличие ошибок
3. Убедитесь, что API ключ имеет достаточный баланс

## Дополнительные настройки

### Кастомный домен

1. В настройках сервиса перейдите в **"Custom Domains"**

Если нужно использовать разные настройки для разных окружений, можно создать отдельные сервисы или использовать переменные окружения Render.
