# BotHub Chat - Клиентское приложение

Современное интерактивное приложение для общения с AI через LangChain и BotHub Chat API.

## Возможности

- 💬 **Интерактивный чат** с поддержкой стриминга ответов
- ⚙️ **Настройки системного промпта** для кастомизации поведения AI
- 🎛️ **Расширенные параметры генерации**:
  - Temperature (температура)
  - Max Tokens (максимальная длина ответа)
  - Top P (nucleus sampling)
  - Top K (ограничение токенов)
  - Frequency Penalty (штраф за повторения)
  - Presence Penalty (штраф за новые темы)
- 🎨 **Современный дизайн** с градиентами и анимациями
- 📱 **Адаптивный интерфейс** для всех устройств

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
VITE_API_URL=http://localhost:3000/api
```

**Примечание:** Если сервер запущен на другом порту или хосте, измените URL соответственно.

### 3. Запуск приложения

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173` (или другому порту, указанному Vite).

### 4. Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`.

## Использование

### Отправка сообщений

1. Введите сообщение в поле ввода
2. Нажмите Enter или кнопку отправки
3. Ответ AI будет отображаться в реальном времени (стриминг)

### Настройка AI

1. Нажмите на кнопку настроек (⚙️) в правом верхнем углу
2. Настройте системный промпт для определения роли AI
3. Измените параметры генерации по необходимости
4. Настройки применяются автоматически

### Очистка чата

Нажмите на кнопку корзины (🗑️) в правом верхнем углу для очистки истории сообщений.

## Технологии

- **React 19** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **CSS3** - стилизация с градиентами и анимациями

## Требования

- Node.js 18+ 
- npm или yarn
- Запущенный сервер на порту 3000 (или другой, указанный в `.env`)
