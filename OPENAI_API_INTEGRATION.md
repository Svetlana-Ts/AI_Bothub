# Интеграция OpenAI API в Node.js приложение

## Принципы подключения AI через API (OpenAI API)

### 1. Основные принципы работы с OpenAI API

#### 1.1. Аутентификация
- OpenAI API использует **API ключ** для аутентификации
- Ключ передается в заголовке `Authorization: Bearer YOUR_API_KEY`
- Ключ должен храниться в переменных окружения (никогда не коммитьте в репозиторий!)

#### 1.2. Модель gpt-4o-mini
- Модель `gpt-4o-mini` (ранее известная как gpt-mini-5) - это оптимизированная версия GPT-4
- Быстрая и экономичная модель для большинства задач
- Поддерживает те же возможности, что и GPT-4, но с меньшей стоимостью

#### 1.3. Типы запросов
- **Chat Completions API** - основной способ взаимодействия с моделями GPT
- Использует формат сообщений: `system`, `user`, `assistant`
- Поддерживает стриминг ответов для лучшего UX

#### 1.4. Обработка ошибок
- Всегда обрабатывайте ошибки API (rate limits, invalid keys, network issues)
- Используйте retry логику для временных сбоев
- Валидируйте входные данные перед отправкой

#### 1.5. Безопасность
- Никогда не передавайте API ключ на клиент
- Используйте переменные окружения для конфигурации
- Ограничивайте количество запросов (rate limiting)
- Валидируйте и санитизируйте пользовательский ввод

## Пошаговая инструкция интеграции

### Шаг 1: Установка зависимостей

```bash
npm install express dotenv openai
```

### Шаг 2: Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
OPENAI_API_KEY=your_api_key_here
PORT=3000
```

### Шаг 3: Создание сервиса для работы с OpenAI

Создайте модуль `services/openaiService.js` для инкапсуляции логики работы с API.

### Шаг 4: Создание Express.js роутов

Создайте роуты для обработки запросов к AI.

### Шаг 5: Обработка ошибок и валидация

Добавьте middleware для обработки ошибок и валидации данных.
